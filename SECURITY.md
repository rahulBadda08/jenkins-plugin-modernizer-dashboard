# Security Policy

## Supported Versions

Only the latest release / `main` branch is actively maintained with security updates.

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `main`           | :white_check_mark: |
| < 1.0.0          | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or security-sensitive defect in this repository, please do not disclose it publicly on public issues or community forums.

Instead, report it responsibly:

1. **GitHub Security Advisory**: Open a private draft security advisory under the repository's **Security** > **Advisories** tab.
2. **Details to Include**:
   - Description of the vulnerability.
   - Proof-of-concept steps or reproduction script.
   - Potential impact on client-side state, exports, or CI automation.
3. **Response Timeline**:
   - Acknowledgment: within 48 hours.
   - Triage and mitigation patch: within 7 business days.
